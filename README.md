# 🎨 RGB Color Generator Android Application

An Android application that allows users to create custom colors using Red, Green, and Blue (RGB) values and displays the corresponding HEX color code.

---

📱 About the Project

RGB Color Generator is a simple and user-friendly Android application designed for experimenting with RGB color values.

---

Users can enter values for:

🔴 Red
🟢 Green
🔵 Blue

The application combines these values to generate a custom color and displays both the color preview and its HEX code.

---

## ✨ Features

🎨 Generate custom colors using RGB values

🔴 Enter Red channel values

🟢 Enter Green channel values

🔵 Enter Blue channel values

🔢 Display the HEX color code

## 🎯 How It Works

The RGB Color Generator creates a custom color by combining three color channels: **Red**, **Green**, and **Blue**.

### Process

1. Enter a value for the **Red** channel.
2. Enter a value for the **Green** channel.
3. Enter a value for the **Blue** channel.
4. The application combines the three RGB values.
5. The generated color is displayed in the **color preview**.
6. The corresponding **HEX color code** is displayed below the preview.

### Example

RGB Values

Red:    255
Green:  0
Blue:   0

HEX:    #FF0000
